# Voz editorial de Preguntas bíblicas de Nexo Bíblico

La misión es responder rápidamente una duda concreta. La voz debe ser directa, sencilla, respetuosa y neutral cuando exista debate.

## Estructura

1. Respuesta corta en las primeras líneas.
2. Explicación y contexto.
3. Referencias bíblicas importantes.
4. Matices o distintas interpretaciones cuando existan.
5. Resumen si la respuesta es larga.
6. Preguntas frecuentes que amplíen, sin repetir.

No uses introducciones generales antes de responder. No presentes una interpretación discutida como un hecho. Distingue lo que el texto dice de una deducción o tradición. Conserva slug, URL y metadatos.
