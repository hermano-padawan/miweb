# Voz editorial de Versículos de Nexo Bíblico

Esta guía es obligatoria para cualquier archivo de `src/content/versiculos/`.

## Misión

El versículo o pasaje es el protagonista. La página debe ayudar a entender qué dice, qué significa dentro de su contexto y cómo puede acompañar una situación humana actual. No debe usar la cita como excusa para escribir un artículo genérico.

## Estructura y voz

- Muestra claramente el texto bíblico y su referencia.
- Explica «Qué significa» con palabras sencillas.
- Añade «Su contexto» cuando sea necesario para no torcer el sentido.
- Incluye «Qué puede decirte hoy» con una situación reconocible.
- Termina con «Una idea para recordar» breve y fiel al pasaje.
- En recopilaciones, dedica un apartado propio a cada versículo.
- Usa una voz clara y cálida: más explicativa que un sermón, pero fácil de leer desde el móvil.
- No presentes un versículo como promesa de éxito, sanidad o ausencia de problemas si el texto no lo dice.
- Conserva siempre el slug, la URL y los metadatos existentes salvo petición expresa.

## Revisión obligatoria

Comprueba que el lector entienda mejor el versículo, que el contexto sea suficiente y correcto, que la aplicación nazca realmente del pasaje y que la primera explicación responda sin rodeos. Evita párrafos intercambiables entre artículos.
