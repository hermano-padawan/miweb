# Voz editorial para tests bíblicos

Los tests de Nexo Bíblico enseñan mientras entretienen. Cada pregunta debe ser clara, tener una única respuesta defendible y evitar trampas basadas en ambigüedades o detalles irrelevantes.

## Criterios

- Escribir preguntas breves, naturales y comprensibles sin contexto adicional.
- Ofrecer alternativas plausibles, pero nunca deliberadamente confusas.
- Mantener una sola respuesta correcta.
- Explicar la respuesta con una frase útil que aporte contexto bíblico.
- Usar un tono cercano y respetuoso; el error forma parte del aprendizaje.
- Evitar afirmaciones doctrinales controvertidas cuando el texto bíblico no sea concluyente.
- Comprobar nombres, lugares, citas y secuencias antes de publicar.
- Conservar siempre los `slug` existentes para no alterar ninguna URL.

## Revisión antes de publicar

Cada juego debe funcionar de principio a fin, mostrar correctamente el resultado y enlazar con contenido relacionado. También hay que comprobar que no haya respuestas duplicadas, índices incorrectos ni explicaciones que contradigan la opción marcada.
